# Background music

Place the two game music files in this directory with these exact names:

- `home.mp3` — plays on the home, lobby, and informational pages.
- `ingame.mp3` — plays while the player is on a game route.
- `conclusion.mp3` — plays when a match reaches its final result.
- `click.wav` — plays for enabled button presses and card selections.
- `win.wav` — plays when the local player wins a round.
- `lose.wav` — plays when the local player loses a round.

Both files are looped automatically. For the smoothest loop, export them without leading or trailing silence.
